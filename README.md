#🛍️ FashionHub
A modern fashion product page built with HTML and CSS.
FashionHub is a frontend practice project focused on creating a clean and modern e-commerce product interface with attention to layout, spacing, typography, colors, and visual details.


##✨ Features
-🛒 Modern fashion product interface
-⭐️ Product rating and reviews
-🎨 Product color selection
-📏 Product size selection
-💰 Product price and discount
-📊 Customer recommendation percentage
-🖼️ Product images and custom SVG icons
-📱 Responsive layout
-🎯 Clean and organized UI


##🛠️ Technologies
.HTML5
.CSS3
.Flexbox
.CSS Grid
.SVG
.Responsive Web Design
