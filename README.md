# 🛍️ FashionHub

A modern and responsive fashion product page built with HTML and CSS.
FashionHub is a frontend practice project focused on creating a clean e-commerce product interface with attention to layout, spacing, typography, colors, and reusable CSS styling.

## ✨ Features

- 🛒 Modern fashion product layout
- ⭐️ Product rating and review section
- 🎨 Color selection
- 📏 Size selection
- 💰 Product pricing and discount display
- 📊 Customer recommendation percentage
- 🖼️ Product imagery and custom icons
- 📱 Responsive and clean interface
- 🎯 Carefully structured HTML and CSS

  ## 🛠️ Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- SVG Icons
- Responsive Design

## 🚀 Getting Started
1. Clone the repository
2. Open the project.
Open the project folder in VS Code.
3. Run the website. 
Open index.html in your browser, or use the Live Server extension in VS Code for a better development experience.

## 🎨 Project Focus
This project was created to practice and improve frontend development skills, especially:
- Page layout and positioning
- Flexbox and CSS Grid
- Spacing and alignment
- Typography
- Borders and border-radius
- Colors and visual hierarchy
- Working with images and SVG icons
- Building a product interface from a visual reference

## 📚 What I Learned
 - While building FashionHub, I practiced turning a visual design into a structured webpage and learned how to control individual elements using modern CSS layout techniques.
- The project also helped me improve my understanding of Flexbox, Grid, spacing, alignment, and responsive UI design.
